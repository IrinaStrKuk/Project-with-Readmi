# LearnTrack Server  
Учебный проект для управления учебными проектами студентов.  

## Технологии  
- Java 17  
- Spring Boot  
- PostgreSQL  
- GitHub API  

## Запуск  
1. Клонируйте репозиторий.  
2. Настройте `application.properties`.  
3. Запустите через `mvn spring-boot:run`.
